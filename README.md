## Project Overview
This repository contains the practical implementation of Computer Vision techniques using Python, OpenCV and Google Colab.

## Tasks Implemented

1. **Image Processing and Segmentation**
   - Noise modelling
   - Spatial filtering
   - Image segmentation
   - PSNR and SSIM evaluation

2. **Feature Extraction and Matching**
   - Histogram of Oriented Gradients (HOG)
   - SIFT keypoint detection
   - Feature matching
   - Rotation and scaling comparison

3. **Object Detection**
   - Viola-Jones face detection
   - YOLOv8 object detection

4. **Video Motion Estimation**
   - Video frame extraction
   - Frame differencing
   - Lucas-Kanade optical flow
   - GMM/MOG2 background subtraction
